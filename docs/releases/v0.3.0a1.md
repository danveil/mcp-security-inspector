# MCP Tool Security Inspector v0.3.0a1

This is an **alpha prerelease** for evaluation, research inspection, and defensive testing. It is not a production-readiness claim.

## Highlights

- Five post-unblinding exploratory rules: `PI-002`, `HID-002`, `SEC-002`, `OBF-005`, and `MIS-002`.
- Bounded depth-one representation handling with strict UTF-8 and inert evidence rendering.
- Improved relation-local context and negation scoping for injection, concealment, and sensitive-data findings.
- Strict JSON duplicate-key and non-finite-number rejection across security-significant entry points.
- Deterministic per-tool, per-report, and retained-evidence budgets with explicit truncation status.
- Compatibility-aware validation and comparison of preserved historical experiment artifacts.
- Immutable preservation of the original v0.2 H0, Day 3C analysis, and authentic Day 4C exploratory artifact.
- Raw-source preservation, icon-text inspection without resource retrieval, and strict malformed-schema rejection.
- Built-in/custom rule-ID collision protection and duplicate-baseline rejection.
- Expanded hostile-input, historical-compatibility, packaging, clean-wheel, and reproducibility tests.

## Research status

The original v0.2 H0 remains the authoritative first confirmatory result. The v0.3 result on that same, already exposed holdout is post-unblinding exploratory evidence only. It does not demonstrate improved generalization. A fresh untouched, independently reviewed, preregistered holdout is required for any new confirmatory claim.

See the [public research status](../research-status.md) and [reproducibility guide](../reproducibility.md) for metrics, hashes, artifact paths, and safe inspection commands.

## Safety boundary

The inspector performs deterministic defensive static analysis. It does not invoke scanned tools, execute metadata, retrieve icon resources, follow metadata URLs, send catalogs to a model, or enable arbitrary remote retrieval. Optional MCP retrieval is explicitly loopback-only and bounded.

## Installation from source

```bash
git clone https://github.com/danveil/mcp-security-inspector.git
cd mcp-security-inspector
python -m venv .venv
python -m pip install .
mcpsec --version
mcpsec demo
```

Expected version: `0.3.0a1`.

PyPI publication is not part of this release operation.
