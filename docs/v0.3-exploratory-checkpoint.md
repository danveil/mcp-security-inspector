## Scientific status

The original v0.2 H0 is the authoritative confirmatory result from the first independent holdout: recall 20.83%, F1 28.57%, and false-positive rate 25.00%.

The v0.3 result on that same, now-exposed holdout is post-unblinding exploratory evidence: recall 45.83%, F1 53.66%, and false-positive rate 25.00%. It must not be described as H0 v2, independent confirmation, or validated generalization. A new untouched, independently reviewed, preregistered holdout is required for a confirmatory v0.3 claim.
